## 1. Design

- [ ] 1.1 盘点系统内表格的公共入口，包括全局插件、表格封装组件和列配置处理逻辑。
- [ ] 1.2 明确自动列宽的默认策略、例外列范围和宽度上限规则。
- [ ] 1.3 明确列宽重算触发时机及与固定列、横向滚动的兼容要求。

## 2. Implementation

- [ ] 2.1 在公共表格能力层统一接入自动列宽逻辑，避免页面逐个重复实现。
- [ ] 2.2 为选择列、序号列、展开列、操作列和显式固定宽度列保留例外处理。
- [ ] 2.3 在数据刷新、分页切换、动态显隐列和容器尺寸变化时触发列宽重算。
- [ ] 2.4 修复或规避自动列宽启用后可能出现的固定列错位、表头错位和滚动异常。

## 3. Verification

- [ ] 3.1 验证常规业务表格能够根据表头和内容自动拉宽，无需逐列配置固定宽度。
- [ ] 3.2 验证长文本列达到上限后以省略方式展示，并可查看完整内容。
- [ ] 3.3 验证分页、搜索、刷新、切换列后列宽能够重新计算。
- [ ] 3.4 验证固定列、排序、筛选和横向滚动在改造后行为正常。
