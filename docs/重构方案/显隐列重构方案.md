# 显隐列重构方案

## 1. 现状分析

### 1.1 当前问题
当前的显隐列实现存在以下问题：

1. **硬编码问题**：每个表格列都需要手动添加 `v-if="columns[index].visible"`
2. **维护困难**：新增或删除列时需要同时修改多个地方
3. **性能问题**：频繁的条件渲染导致DOM重绘和重排
4. **可扩展性差**：无法动态配置列的其他属性（如宽度、对齐方式等）
5. **代码冗余**：相同的逻辑在多个文件中重复实现

### 1.2 当前实现方式
```vue
<!-- 当前的硬编码方式 -->
<el-table-column v-if="columns[0].visible" label="ID" align="center" prop="id" />
<el-table-column v-if="columns[1].visible" label="客户名称" align="center" prop="companyName" />
```

## 2. 重构目标

### 2.1 设计目标
1. **配置化**：通过配置对象动态生成表格列
2. **组件化**：创建可复用的动态表格组件
3. **性能优化**：减少不必要的DOM操作
4. **易维护**：统一的配置管理和使用方式
5. **可扩展**：支持更多列属性的动态配置

### 2.2 预期效果
- 新增列只需在配置中添加一项
- 删除列只需在配置中移除对应项
- 支持列的排序、宽度、对齐等属性配置
- 统一的显隐控制逻辑

## 4. 实现方案

### 4.1 第一步：创建 ColumnManager 工具类

```javascript
// src/utils/columnManager.js
class ColumnManager {
  constructor(storageKey) {
    this.storageKey = storageKey;
    this.columns = [];
  }

  // 初始化列配置
  initColumns(defaultColumns) {
    const savedColumns = this.getStoredColumns();
    if (savedColumns && savedColumns.length > 0) {
      this.columns = this.mergeColumns(defaultColumns, savedColumns);
    } else {
      this.columns = defaultColumns;
      this.saveColumns();
    }
    return this.columns;
  }

  // 获取可见列
  getVisibleColumns() {
    return this.columns.filter(col => col.visible);
  }

  // 更新列可见性
  updateColumnVisibility(key, visible) {
    const column = this.columns.find(col => col.key === key);
    if (column) {
      column.visible = visible;
      this.saveColumns();
    }
  }

  // 保存到本地存储
  saveColumns() {
    localStorage.setItem(this.storageKey, JSON.stringify(this.columns));
  }

  // 从本地存储获取
  getStoredColumns() {
    const stored = localStorage.getItem(this.storageKey);
    return stored ? JSON.parse(stored) : null;
  }

  // 合并默认配置和存储配置
  mergeColumns(defaultColumns, storedColumns) {
    return defaultColumns.map(defaultCol => {
      const storedCol = storedColumns.find(col => col.key === defaultCol.key);
      return storedCol ? { ...defaultCol, ...storedCol } : defaultCol;
    });
  }

  // 重置为默认配置
  resetToDefault(defaultColumns) {
    this.columns = [...defaultColumns];
    this.saveColumns();
    return this.columns;
  }
}

export default ColumnManager;
```

### 4.2 第二步：创建 DynamicTable 组件

```vue
<!-- src/components/DynamicTable/index.vue -->
<template>
  <el-table
    ref="table"
    v-bind="$attrs"
    v-on="$listeners"
    :data="data"
  >
    <!-- 动态生成的列 -->
    <template v-for="column in visibleColumns">
      <!-- 普通列 -->
      <el-table-column
        v-if="!column.slot"
        :key="column.key"
        v-bind="getColumnProps(column)"
      />
      
      <!-- 带插槽的列 -->
      <el-table-column
        v-else
        :key="column.key"
        v-bind="getColumnProps(column)"
      >
        <template slot-scope="scope">
          <slot 
            :name="column.slot" 
            :row="scope.row" 
            :column="column" 
            :$index="scope.$index"
          />
        </template>
      </el-table-column>
    </template>

    <!-- 操作列插槽 -->
    <slot name="action" />
  </el-table>
</template>

<script>
export default {
  name: 'DynamicTable',
  props: {
    data: {
      type: Array,
      default: () => []
    },
    columns: {
      type: Array,
      required: true
    }
  },
  computed: {
    visibleColumns() {
      return this.columns.filter(col => col.visible !== false);
    }
  },
  methods: {
    getColumnProps(column) {
      const props = { ...column };
      // 移除非 el-table-column 属性
      delete props.key;
      delete props.visible;
      delete props.slot;
      return props;
    }
  }
};
</script>
```

## 9. 维护规范

### 9.1 配置规范
- 列配置对象必须包含 `key` 和 `label`
- `key` 值必须在表格中唯一
- 新增属性需要更新类型定义

### 9.2 命名规范
- 存储 key 使用 `{页面名}-columns` 格式
- 列 key 使用 camelCase 命名
- 插槽名称使用 kebab-case 命名

### 9.3 版本兼容
- 配置结构变更需要提供迁移脚本
- 保持向后兼容至少一个版本
- 变更需要更新文档和示例

## 10. 常见问题解决

### 10.1 配置丢失问题
**问题**：刷新页面后列配置丢失
**解决**：检查 localStorage 存储和读取逻辑

### 10.2 渲染性能问题
**问题**：大量列时渲染缓慢
**解决**：实现列虚拟化或分页显示

### 10.3 兼容性问题
**问题**：旧版本数据无法正常显示
**解决**：实现配置迁移和默认值处理
