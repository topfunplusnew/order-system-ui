# 动态表单配置系统升级说明

## 1. 升级概述

本次升级实现了更加智能的配置系统，支持：

- 通过 `includeInForm` 属性控制字段是否包含在表单中
- 动态生成 `defaultForm` 对象，而不是静态写死
- 统一的配置管理和类型智能识别

## 2. 主要改进

### 2.1 新增 `includeInForm` 属性

每个字段配置现在都包含 `includeInForm` 属性：

```javascript
{
  key: 'id',
  prop: 'id',
  label: 'ID',
  includeInForm: false, // 不包含在表单中
  formConfig: {
    type: 'input',
    show: false,
    readonly: true
  }
}
```

#### 属性说明：

- `includeInForm: true` - 字段包含在表单数据中（默认值）
- `includeInForm: false` - 字段不包含在表单数据中

### 2.2 动态生成 defaultForm

#### 改进前（静态配置）：

```javascript
export default {
  tableColumns: [...],
  defaultForm: {
    id: null,
    companyName: null,
    relationName: null,
    // ... 手动维护所有字段
  }
};
```

#### 改进后（动态生成）：

```javascript
export default {
  tableColumns: [
    // 配置中包含所有字段信息
  ],
  // defaultForm 自动根据 tableColumns 动态生成
};
```

### 2.3 智能类型识别

配置管理器会根据字段类型自动设置合适的默认值：

```javascript
/**
 * 根据字段类型获取默认值
 */
getDefaultValueByType(column) {
  const formConfig = column.formConfig;

  // 如果配置中指定了默认值，使用指定的值
  if (formConfig && formConfig.hasOwnProperty('defaultValue')) {
    return formConfig.defaultValue;
  }

  // 根据字段类型返回合适的默认值
  switch (formConfig.type) {
    case 'number':
      return null;
    case 'switch':
      return false;
    case 'checkbox':
      return [];
    case 'date':
    case 'time':
    case 'datetime':
      return null;
    case 'select':
      return formConfig.multiple ? [] : null;
    default:
      return null;
  }
}
```

## 4. 配置管理器升级

### 4.1 新增方法

#### `generateDefaultFormFromColumns()`

```javascript
/**
 * 根据tableColumns动态生成默认表单数据
 * @returns {Object} 动态生成的表单数据对象
 */
generateDefaultFormFromColumns() {
  const formData = {};

  this.tableColumns.forEach(column => {
    // 检查是否需要包含在表单中
    const includeInForm = column.includeInForm !== false; // 默认为true

    if (includeInForm && column.prop) {
      // 根据字段类型设置默认值
      formData[column.prop] = this.getDefaultValueByType(column);
    }
  });

  return formData;
}
```

#### `getDefaultValueByType()`

根据字段类型智能设置默认值

### 4.2 更新的方法

#### `getFormConfig()`

```javascript
getFormConfig() {
  return this.tableColumns.filter(col => {
    // 检查是否包含在表单中和是否显示
    const includeInForm = col.includeInForm !== false; // 默认为true
    const showInForm = col.formConfig && col.formConfig.show;
    return includeInForm && showInForm;
  }).sort((a, b) => (a.formConfig.order || 999) - (b.formConfig.order || 999));
}
```

## 5. 优势对比

### 5.1 维护性提升

| 方面       | 改进前               | 改进后                        |
| ---------- | -------------------- | ----------------------------- |
| 新增字段   | 需要修改多个地方     | 只需在配置中添加一项          |
| 删除字段   | 需要清理多个位置     | 设置 `includeInForm: false`   |
| 默认值管理 | 手动维护 defaultForm | 自动生成，支持类型智能识别    |
| 字段分类   | 无明确标识           | 通过 `includeInForm` 清晰分类 |

## 6. 使用指南

### 6.1 添加新字段

```javascript
// 1. 在 tableColumns 中添加配置
{
  key: 'newField',
  prop: 'newField',
  label: '新字段',
  visible: true,        // 是否在表格中显示
  includeInForm: true,  // 是否包含在表单中
  formConfig: {
    type: 'input',
    show: true,         // 是否在表单中显示
    placeholder: '请输入新字段',
    defaultValue: '',   // 可选：指定默认值
    col: { span: 12 },
    order: 20
  }
}

// 2. defaultForm 会自动包含这个字段
// 无需手动修改 defaultForm 对象
```

### 6.2 字段分类最佳实践

#### 业务数据字段

```javascript
includeInForm: true,  // 包含在表单中
visible: true,        // 在表格中显示
formConfig: {
  show: true,         // 在表单中显示
  // ...其他配置
}
```

#### 计算字段

```javascript
includeInForm: false, // 不包含在表单中（由其他字段计算得出）
visible: true,        // 在表格中显示
formConfig: {
  type: 'computed',
  show: false,
  computed: 'field1 + field2'
}
```

#### 系统字段

```javascript
includeInForm: false, // 不包含在表单中
visible: false,       // 不在表格中显示
// 无需 formConfig
```

#### 隐藏业务字段

```javascript
includeInForm: true,  // 包含在表单中（用于数据传输）
visible: false,       // 不在表格中显示
formConfig: {
  show: false,        // 不在表单中显示（隐藏字段）
  defaultValue: 'defaultValue'
}
```

## 7. 迁移指南

### 7.1 现有配置迁移

1. **为所有字段添加 `includeInForm` 属性**

   ```javascript
   // 原来的配置
   {
     key: 'field1',
     prop: 'field1',
     label: '字段1'
   }

   // 迁移后的配置
   {
     key: 'field1',
     prop: 'field1',
     label: '字段1',
     includeInForm: true  // 新增这一行
   }
   ```

2. **移除静态 defaultForm**

   ```javascript
   // 原来的配置
   export default {
     tableColumns: [...],
     defaultForm: { ... }  // 删除这个对象
   };

   // 迁移后的配置
   export default {
     tableColumns: [...]   // 只保留 tableColumns
   };
   ```

3. **配置字段默认值**
   ```javascript
   {
     key: 'status',
     prop: 'status',
     includeInForm: true,
     formConfig: {
       type: 'select',
       defaultValue: 'active'  // 在 formConfig 中指定默认值
     }
   }
   ```

## 8. 总结

通过这次升级，我们实现了：

✅ **更智能的配置管理**：通过 `includeInForm` 属性精确控制字段用途

✅ **动态表单生成**：根据配置自动生成 `defaultForm`，减少维护工作

✅ **类型智能识别**：根据字段类型自动设置合适的默认值

✅ **更好的可维护性**：单一数据源，避免配置重复和不一致

✅ **更强的扩展性**：新增字段只需要添加一个配置项

这为项目的配置系统奠定了更加先进和灵活的基础，大大提升了开发效率和代码质量。
