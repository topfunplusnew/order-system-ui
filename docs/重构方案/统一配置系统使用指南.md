# 统一配置系统使用指南

## 概述

本系统实现了表格列配置和表单配置的统一管理，通过 JSON 配置文件来定义表格显示和表单渲染的所有细节，实现了配置化驱动的 UI 渲染方案。

## 核心组件

### 1. ConfigManager (配置管理器)

- 位置：`src/utils/configManager.js`
- 功能：统一管理表格列配置和表单配置，提供配置解析和数据处理能力

### 2. DynamicForm (动态表单组件)

- 位置：`src/components/DynamicForm/index.vue`
- 功能：根据配置动态渲染表单，支持多种表单控件类型

### 3. 配置文件

- 位置：`src/views/system/company/columns.json`
- 功能：定义表格列和表单字段的所有配置信息

## 配置文件结构

### 完整配置示例

```json
{
  "tableColumns": [
    {
      "key": "companyName",
      "prop": "companyName",
      "label": "客户名称",
      "align": "center",
      "showOverflowTooltip": true,
      "visible": true,
      "formConfig": {
        "type": "input",
        "show": true,
        "required": true,
        "placeholder": "请输入客户名称",
        "rules": [
          { "required": true, "message": "请输入客户名称", "trigger": "blur" },
          {
            "min": 2,
            "max": 50,
            "message": "公司名称长度在2-50个字符",
            "trigger": "blur"
          }
        ],
        "col": { "span": 12 },
        "order": 1
      }
    }
  ],
  "defaultForm": {
    "id": null,
    "companyName": null,
    "relationName": null
  }
}
```

### 配置字段说明

#### 表格列配置 (tableColumns)

- `key`: 唯一标识符
- `prop`: 数据字段名
- `label`: 显示标签
- `align`: 对齐方式
- `width`: 列宽
- `visible`: 是否显示
- `showOverflowTooltip`: 是否显示溢出提示

#### 表单配置 (formConfig)

- `type`: 控件类型 (`input`, `select`, `textarea`, `number`, `date`, `time`, `switch`, `radio`, `checkbox`)
- `show`: 是否在表单中显示
- `required`: 是否必填
- `placeholder`: 占位符文本
- `rules`: 验证规则数组
- `col`: 栅格布局配置
- `order`: 排序权重
- `options`: 选择器选项数据源
- `optionLabel`: 选项标签字段
- `optionValue`: 选项值字段
- `change`: 变化时触发的方法名

#### 默认表单数据 (defaultForm)

定义表单的初始数据结构和默认值。

## 使用方法

### 1. 在页面组件中使用

```vue
<script>
import { createConfigManager } from "@/utils/configManager";
import columnConfig from "./columns.json";

export default {
  data() {
    return {
      configManager: null,
      tableColumns: [],
    };
  },
  created() {
    // 初始化配置管理器
    this.configManager = createConfigManager(columnConfig);
    this.tableColumns = this.configManager.getTableColumns();
  },
  methods: {
    // 获取默认表单数据
    getDefaultFormData() {
      return this.configManager.getDefaultForm();
    },

    // 新增操作
    handleAdd() {
      const defaultForm = this.getDefaultFormData();
      this.openDialog(CompanyForm, "添加信息", "600px", {
        formData: defaultForm,
        isEdit: false,
      });
    },
  },
};
</script>
```

### 2. 在表单组件中使用

```vue
<template>
  <DynamicForm
    ref="dynamicForm"
    :config="columnConfig"
    :form-data="formData"
    :is-edit="isEdit"
    :external-data="externalData"
    @submit="handleFormSubmit"
    @cancel="handleFormCancel"
  />
</template>

<script>
import DynamicForm from "@/components/DynamicForm";
import columnConfig from "./columns.json";

export default {
  components: { DynamicForm },
  props: {
    formData: { type: Object, default: () => ({}) },
    isEdit: { type: Boolean, default: false },
  },
  data() {
    return {
      columnConfig,
      externalData: {
        provinceList: [], // 外部数据
        cityList: [],
      },
    };
  },
  methods: {
    async handleFormSubmit(formData) {
      // 处理表单提交
    },
  },
};
</script>
```

## 验证规则配置

### 内置验证器

系统支持以下内置验证器：

- `validateChineseName`: 中文姓名验证
- `validationRules.required`: 必填验证
- `validationRules.phone`: 手机号验证

### 自定义验证规则

```json
{
  "rules": [
    { "required": true, "message": "此字段为必填项", "trigger": "blur" },
    { "min": 2, "max": 10, "message": "长度在2-10个字符", "trigger": "blur" },
    { "pattern": "^[0-9]+$", "message": "只能输入数字", "trigger": "blur" },
    { "validator": "validateChineseName", "trigger": "blur" }
  ]
}
```

## 布局配置

### 栅格布局

使用 Element UI 的栅格系统，通过 `col` 配置控制字段宽度：

```json
{
  "col": { "span": 12 }, // 占据12个栅格，即50%宽度
  "col": { "span": 24 }, // 占据24个栅格，即100%宽度
  "col": { "span": 8 } // 占据8个栅格，即33.33%宽度
}
```

### 字段排序

通过 `order` 属性控制字段在表单中的显示顺序：

```json
{
  "order": 1 // 数值越小越靠前
}
```

## 事件处理

### 字段变化事件

在表单组件中，可以监听字段变化事件：

```vue
<DynamicForm @field-change="handleFieldChange" />

<script>
methods: {
  handleFieldChange({ prop, value }) {
    console.log(`字段 ${prop} 变化为:`, value);
    // 处理字段变化逻辑
  }
}
</script>
```

### 选择器变化处理

在配置中指定 `change` 方法名，在组件中实现对应方法：

```json
{
  "type": "select",
  "change": "changeProvince"
}
```

```javascript
methods: {
  changeProvince(value) {
    // 处理省份变化
    this.updateCityList(value);
  }
}
```

## 外部数据注入

对于需要外部数据的选择器（如省市联动），通过 `external-data` 属性注入：

```vue
<DynamicForm :external-data="externalData" />

<script>
data() {
  return {
    externalData: {
      provinceList: [],
      cityList: []
    }
  };
}
</script>
```

## 最佳实践

### 1. 配置文件管理

- 每个页面的配置文件放在对应的页面目录下
- 配置文件命名使用 `columns.json`
- 保持配置文件的可读性，添加必要的注释

### 2. 字段命名规范

- `key` 和 `prop` 使用 camelCase 命名
- `label` 使用中文描述，简洁明了
- 布尔型字段使用 `is` 或 `has` 前缀

### 3. 验证规则设计

- 必填字段放在规则数组的第一位
- 长度验证紧跟在必填验证之后
- 格式验证放在最后

### 4. 性能优化

- 大型表单考虑分组渲染
- 选择器数据量大时使用懒加载
- 合理使用字段的 `show` 属性控制渲染

## 迁移指南

### 从传统表单迁移到配置化表单

1. **创建配置文件**

   ```bash
   # 在页面目录下创建 columns.json
   touch src/views/system/yourpage/columns.json
   ```

2. **定义配置结构**

   - 分析现有表单字段
   - 定义表格列配置
   - 定义表单配置
   - 设置默认表单数据

3. **改造页面组件**

   - 引入 ConfigManager
   - 替换硬编码的列定义
   - 使用配置化的默认表单数据

4. **改造表单组件**
   - 替换为 DynamicForm 组件
   - 调整事件处理逻辑
   - 测试各种表单控件

### 常见问题解决

1. **配置不生效**

   - 检查 JSON 格式是否正确
   - 确认字段名拼写无误
   - 验证导入路径是否正确

2. **验证规则失效**

   - 检查验证器名称是否正确
   - 确认自定义验证器已注册
   - 验证规则格式是否符合要求

3. **选择器数据为空**
   - 检查 `external-data` 是否正确传入
   - 确认数据源字段名与配置一致
   - 验证数据加载时机

## 总结

通过配置化系统，我们实现了：

1. **统一管理**：表格列和表单字段配置集中管理
2. **动态渲染**：根据配置动态生成 UI 组件

4. **易于维护**：修改配置即可调整 UI，无需改动代码
5. **类型安全**：配置结构化，减少运行时错误

这套系统大大提高了开发效率，降低了维护成本，同时保证了界面的一致性和可扩展性。
