# @order-system/shared

共享工具函数、常量和类型定义包。

## 使用方式

```javascript
import { getToken, setToken } from '@order-system/shared/utils/auth';
import { API_BASE_URL, HTTP_STATUS } from '@order-system/shared/constants';
```

## 目录结构

```
shared/
├── utils/          # 通用工具函数
├── constants/      # 常量定义
├── types/          # 类型定义
└── index.js        # 入口文件
```
