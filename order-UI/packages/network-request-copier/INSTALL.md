# 安装指南

## Chrome 浏览器安装步骤

### 1. 准备图标文件

在安装扩展之前，需要先创建图标文件：

1. 进入 `icons` 目录
2. 创建三个 PNG 图标文件：
   - `icon16.png` (16x16 像素)
   - `icon48.png` (48x48 像素)
   - `icon128.png` (128x128 像素)

**快速创建临时图标的方法：**

使用在线工具：https://www.favicon-generator.org/
- 上传任意图片或使用文字生成图标
- 下载不同尺寸的图标
- 重命名并放置到 `icons` 目录

### 2. 加载扩展

1. 打开 Chrome 浏览器
2. 在地址栏输入：`chrome://extensions/`
3. 开启右上角的 **"开发者模式"** 开关
4. 点击左上角的 **"加载已解压的扩展程序"** 按钮
5. 选择 `packages/network-request-copier` 目录
6. 扩展安装完成！

### 3. 验证安装

安装成功后，你应该能看到：
- 浏览器工具栏中出现扩展图标
- 访问任意网页时，右下角出现蓝色圆形按钮（📋）

## 使用说明

### 查看请求列表

**方法一：点击浮动按钮**
- 访问任意网页
- 点击页面右下角的蓝色圆形按钮
- 在弹出的面板中查看所有网络请求

**方法二：点击扩展图标**
- 点击浏览器工具栏中的扩展图标
- 在弹出窗口中查看请求列表

**方法三：右键菜单**
- 在网页任意位置右键
- 选择"复制请求信息"

### 复制请求信息

1. 在请求列表中找到要复制的请求
2. 点击该请求右侧的 **"复制"** 按钮
3. 请求信息已复制到剪贴板，格式如下：

```json
{
  "请求方法": "POST",
  "请求地址": "https://api.example.com/users",
  "请求载荷": {
    "name": "John",
    "email": "john@example.com"
  },
  "响应结构": {
    "状态码": 200,
    "响应头": [...]
  }
}
```

## 权限说明

扩展需要以下权限：
- **webRequest** - 拦截网络请求
- **storage** - 存储请求数据
- **activeTab** - 访问当前标签页
- **<all_urls>** - 访问所有网站（用于拦截所有请求）

这些权限是扩展正常工作的必要条件。

## 故障排除

### 扩展无法加载

- 确保所有文件都在 `packages/network-request-copier` 目录下
- 确保 `manifest.json` 文件格式正确
- 检查浏览器控制台是否有错误信息

### 看不到浮动按钮

- 刷新网页
- 检查扩展是否已启用
- 打开浏览器控制台查看是否有错误

### 无法拦截请求

- 确保扩展已启用
- 检查扩展权限是否已授予
- 尝试重新加载扩展

### 复制功能不工作

- 检查浏览器是否允许剪贴板访问
- 尝试手动复制（选中文本后 Ctrl+C）
- 查看浏览器控制台是否有错误

## 卸载扩展

1. 访问 `chrome://extensions/`
2. 找到"网络请求复制器"扩展
3. 点击"移除"按钮

## 更新扩展

1. 访问 `chrome://extensions/`
2. 找到"网络请求复制器"扩展
3. 点击刷新图标 🔄
4. 或者重新加载扩展目录
