## 功能说明

### 一键申请流程

1. 用户在佣金列表中选择需要申请的记录
2. 点击"一键申请"按钮
3. 系统显示申请列表对话框
4. 用户可以点击"统一填写申请"来填写申请信息
5. 填写完成后，可以点击"批量申请"提交申请

### 主要功能特性

-   支持批量选择佣金记录进行申请
-   集成了 ApplyPayment 组件来填写申请信息
-   支持表单验证和数据处理
-   包含完整的错误处理和用户反馈
-   保持了原有的 keep-alive 状态管理功能

## 技术细节
