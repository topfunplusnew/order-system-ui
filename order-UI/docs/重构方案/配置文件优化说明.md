# 配置文件优化说明

## 1. 概述

已成功将 `columns.json` 改为 `columns.js`，并按照《校验方法统一调用方案.md》统一使用校验方法，实现了配置系统的进一步优化。

## 2. 主要改进

### 2.1 文件格式升级

- **原格式**: `columns.json` (JSON 静态配置)
- **新格式**: `columns.js` (JavaScript 模块)

#### 优势对比

| 方面     | JSON 格式 | JavaScript 模块 |
| -------- | --------- | --------------- |
| 类型检查 | ❌ 无     | ✅ 有           |
| 代码提示 | ❌ 无     | ✅ 有           |
| 函数引用 | ❌ 不支持 | ✅ 支持         |
| 注释支持 | ❌ 不支持 | ✅ 支持         |
| 动态配置 | ❌ 不支持 | ✅ 支持         |
| 模块化   | ❌ 不支持 | ✅ 支持         |

### 2.2 校验方法统一化

#### 改进前（分散的校验方法）

```javascript
// 各个组件中重复的校验逻辑
rules: [
  { required: true, message: "请输入联系人电话", trigger: "blur" },
  {
    pattern: "^1[3-9]\\d{9}$",
    message: "请输入正确的手机号码",
    trigger: "blur",
  },
];
```

#### 改进后（统一的校验方法）

```javascript
// 引入统一校验方法
import {
  validationRules,
  validatePhone,
  validateChineseName,
} from "@/api/tool";

// 使用预设规则
rules: validationRules.phone;

// 或组合使用
rules: [
  validationRules.required,
  { validator: validateChineseName, trigger: "blur" },
];
```

### 2.3 具体配置示例

#### 手机号校验

```javascript
// 老板电话字段
```

```javascript

// columns.js

```


## 4. 优化效果

### 4.1 代码质量提升

- ✅ **类型安全**: JavaScript 模块提供更好的类型检查
- ✅ **代码复用**: 统一的校验方法避免重复代码
- ✅ **维护性**: 校验规则集中管理，修改影响全局
- ✅ **一致性**: 确保所有表单使用相同的校验标准

### 4.2 开发体验改善

- ✅ **智能提示**: IDE 可以提供更好的代码提示
- ✅ **错误检查**: 编译时可以发现更多错误
- ✅ **重构支持**: 更容易进行代码重构
- ✅ **模块化**: 支持按需导入和树摇优化

### 4.3 校验规则标准化

| 字段类型 | 旧方式          | 新方式                     | 优势               |
| -------- | --------------- | -------------------------- | ------------------ |
| 手机号   | 各自实现正则    | `validationRules.phone`    | 统一标准、易维护   |
| 中文姓名 | 手写校验逻辑    | `validateChineseName`      | 复用性强、测试完善 |
| 必填项   | 重复写 required | `validationRules.required` | 减少冗余、统一提示 |

## 5. 使用指南

### 5.1 在配置文件中使用

```javascript
// 1. 导入校验方法
import {
  validationRules,
  validatePhone,
  validateChineseName,
} from "@/api/tool";

// 2. 在配置中使用
export default {
  tableColumns: [
    {
      key: "phone",
      formConfig: {
        // 方式1: 使用预设规则
        rules: validationRules.phone,

        // 方式2: 使用单个校验方法
        rules: [{ validator: validatePhone, trigger: "blur" }],

        // 方式3: 组合使用
        rules: [
          validationRules.required,
          { validator: validatePhone, trigger: "blur" },
        ],
      },
    },
  ],
};
```

### 5.2 扩展新的校验方法

```javascript
// 在 @/api/tool/index.js 中添加
export const validateCustomRule = (rule, value, callback) => {
  // 自定义校验逻辑
  if (!customCondition(value)) {
    return callback(new Error("自定义错误信息"));
  }
  callback();
};

// 添加到预设规则
export const validationRules = {
  // 现有规则...
  customRule: [
    { required: true, message: "请输入内容", trigger: "blur" },
    { validator: validateCustomRule, trigger: "blur" },
  ],
};
```
