# 弹窗统一方案

## 概述

本项目实现了一套统一的弹窗组件解决方案，通过 `DialogWrapper` 组件和 `common_dialog` 混入，提供了标准化的弹窗管理功能。该方案支持动态组件加载、状态保持、拖拽功能，并解决了多弹窗并存的问题。不过，所有使用 this.openDialog 打开展示的组件，都需要实现 handleReject 和 handleProcess 方法，分别对应弹窗的取消和确定按钮的回调函数

## 核心组件

### 1. DialogWrapper.vue

统一弹窗容器组件，负责：

- 弹窗的显示/隐藏控制
- 动态组件加载和渲染
- 拖拽功能支持
- 组件状态保存和恢复
- 标准化的确认/取消操作

### 2. common_dialog.js

弹窗管理混入，提供：

- 弹窗实例的动态创建和销毁
- 多弹窗状态管理
- 统一的弹窗打开接口
- Keep-alive 场景下的状态处理

## 使用方法

### 全局注册配置

系统已在 `main.js` 中进行了全局注册：

```javascript
// 全局注册通用弹窗混入
Vue.mixin(common_dialog);
// 全局注册通用弹窗组件
Vue.component("DialogWrapper", DialogWrapper);
```

### 基础用法

由于已经全局注册，所有组件都可以直接使用弹窗功能：

1. **直接调用弹窗**（推荐方式）

```javascript
// 不需要引入任何东西，直接调用
this.openDialog(
  ComponentName, // 要显示的组件
  "弹窗标题", // 弹窗标题
  "1500px", // 弹窗宽度
  {
    // 传递给组件的 props
    prop1: value1,
    prop2: value2,
  },
  false // 是否只显示关闭按钮（隐藏确认按钮）
);
```

2. **直接使用 DialogWrapper 组件**（可选方式）

```vue
<template>
  <div>
    <!-- 直接在模板中使用全局组件 -->
    <DialogWrapper
      :current-component="currentComponent"
      :dialog-visible="dialogVisible"
      :dialog-title="dialogTitle"
      :dialog-width="dialogWidth"
      :dialog-props="dialogProps"
      :close-confirm="closeConfirm"
      @close="handleClose"
      @confirm="handleConfirm"
    />
  </div>
</template>
```

### 参数说明

| 参数         | 类型          | 必填 | 默认值 | 说明                             |
| ------------ | ------------- | ---- | ------ | -------------------------------- |
| component    | String/Object | 是   | -      | 要在弹窗中显示的 Vue 组件        |
| title        | String        | 是   | -      | 弹窗标题                         |
| width        | String        | 否   | '50%'  | 弹窗宽度，支持像素值和百分比     |
| props        | Object        | 否   | {}     | 传递给内容组件的属性对象         |
| closeConfirm | Boolean       | 否   | false  | 是否隐藏确认按钮，只显示关闭按钮 |

### 业务组件要求

使用弹窗系统的业务组件必须实现以下两个方法：

```javascript
export default {
  methods: {
    // 确认操作处理函数
    handleProcess() {
      return new Promise((resolve, reject) => {
        // 执行业务逻辑
        // 成功时调用 resolve()
        // 失败时调用 reject(error)
      });
    },

    // 取消/关闭操作处理函数
    handleReject() {
      return new Promise((resolve) => {
        // 执行清理逻辑
        resolve();
      });
    },
  },
};
```

## 使用示例

### 示例 1：数据编辑弹窗

```javascript
// 在任意组件中直接调用（无需引入）
methods: {
  editData(row) {
    this.openDialog(
      EditDataForm,           // 编辑表单组件
      '编辑数据',             // 弹窗标题
      '800px',               // 弹窗宽度
      {                      // 传递数据
        editData: row,
        mode: 'edit'
      },
      false                  // 显示确认按钮
    );
  }
}
```

```javascript
// EditDataForm.vue 组件
export default {
  props: {
    editData: Object,
    mode: String,
  },
  methods: {
    async handleProcess() {
      try {
        // 表单验证
        await this.$refs.form.validate();

        // 提交数据
        await this.submitData();

        this.$message.success("保存成功");
        return Promise.resolve();
      } catch (error) {
        this.$message.error("保存失败");
        return Promise.reject(error);
      }
    },

    handleReject() {
      // 清理操作
      this.resetForm();
      return Promise.resolve();
    },
  },
};
```

### 示例 3：使用全局组件方式

```vue
<template>
  <div>
    <el-button @click="showDialog">打开弹窗</el-button>

    <!-- 直接使用全局注册的 DialogWrapper 组件 -->
    <DialogWrapper
      :current-component="EditForm"
      :dialog-visible="visible"
      :dialog-title="'编辑表单'"
      :dialog-width="'800px'"
      :dialog-props="{ editData: currentRow }"
      :close-confirm="false"
      @close="handleDialogClose"
      @confirm="handleDialogConfirm"
    />
  </div>
</template>

<script>
import EditForm from "./EditForm.vue";

export default {
  data() {
    return {
      visible: false,
      currentRow: {},
      EditForm,
    };
  },
  methods: {
    showDialog() {
      this.visible = true;
    },
    handleDialogClose(callback) {
      callback().finally(() => {
        this.visible = false;
      });
    },
    handleDialogConfirm(callback) {
      callback()
        .then(() => {
          this.visible = false;
          // 刷新数据
        })
        .catch((error) => {
          console.error("操作失败:", error);
        });
    },
  },
};
</script>
```

## 高级特性

### 1. 状态保持

弹窗组件支持在 keep-alive 场景下的状态保持：

- 页面切换时自动隐藏弹窗
- 页面激活时恢复弹窗显示
- 组件内部状态得到保持

### 2. 拖拽功能

弹窗支持以下拖拽操作：

- 标题栏拖拽移动位置
- 边缘拖拽调整大小
- 防止内容区域误操作

### 3. 多弹窗管理

系统支持同时打开多个弹窗：

- 每个弹窗都是独立实例
- 自动管理弹窗的层级关系
- 正确处理弹窗的创建和销毁

## 注意事项

### 1. 组件实现要求

- 业务组件必须实现 `handleProcess` 和 `handleReject` 方法
- `handleProcess` 方法需要返回 Promise
- 失败时应该 reject，成功时 resolve

### 2. 错误处理

- 弹窗系统会自动捕获组件方法的错误
- 确认操作失败时弹窗不会自动关闭
- 建议在业务组件中添加适当的错误提示

### 3. 性能考虑

- 每次打开弹窗都会创建新的组件实例
- 弹窗关闭时会自动销毁实例
- 大型表单建议使用懒加载组件

### 4. 样式注意

- 弹窗会添加到 body 元素中
- 使用 append-to-body 避免层级问题
- 内容组件的样式应该考虑弹窗环境

## 最佳实践

### 1. 组件设计

```javascript
// 推荐的业务组件结构
export default {
  name: "BusinessComponent",
  props: {
    // 明确定义所需的 props
  },
  data() {
    return {
      // 组件状态
    };
  },
  methods: {
    async handleProcess() {
      // 统一的确认处理逻辑
      try {
        await this.validateAndSubmit();
        this.$message.success("操作成功");
        return Promise.resolve();
      } catch (error) {
        this.$message.error(`操作失败: ${error.message}`);
        return Promise.reject(error);
      }
    },

    handleReject() {
      // 统一的取消处理逻辑
      this.cleanup();
      return Promise.resolve();
    },
  },
};
```

### 2. 调用规范

```javascript
// 推荐的调用方式（全局混入后）
openBusinessDialog(data) {
  // 直接调用，无需引入

    () => import('./BusinessComponent.vue'), // 懒加载大型组件

    '800px',
    {
      businessData: data,
      mode: 'edit'
    },
    false
  );
}

// 或者使用全局组件方式
openBusinessDialogWithComponent(data) {
  this.businessDialogVisible = true;
  this.businessDialogProps = {
    businessData: data,
    mode: 'edit'
  };
}
```

created() {

## 迁移指南

如果项目中已有旧的弹窗实现，可以按以下步骤迁移：

### 从手动引入到全局注册的迁移

**旧方式（手动引入）：**

```javascript
import { common_dialog } from "@/views/dashboard/mixins/common/common_dialog";
import DialogWrapper from "@/views/dashboard/components/common/DialogWrapper.vue";

export default {
  mixins: [common_dialog],
  components: { DialogWrapper },
  // ...
};
```

**新方式（全局注册）：**

```javascript
// 无需任何引入，直接使用
export default {
  methods: {
    openSomeDialog() {
      this.openDialog(/* 参数 */);
    },
  },
};
```

### 迁移步骤

1. **移除手动引入**：删除组件中的 `common_dialog` 混入引入
2. **移除组件注册**：删除 `DialogWrapper` 组件的局部注册
3. **直接使用**：直接调用 `this.openDialog()` 或使用 `<DialogWrapper>` 组件
4. **测试验证**：确保弹窗的打开、关闭、确认等功能正常

### 兼容性说明

- 全局注册后，所有组件都可以使用弹窗功能
- 原有的手动引入方式仍然可以正常工作
- 建议统一使用全局注册方式以保持代码一致性

通过这套统一的弹窗方案，可以大大简化弹窗管理的复杂度，提高代码的可维护性和用户体验的一致性。
