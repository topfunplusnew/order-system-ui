## 📖 项目简介

订单管理系统是一个功能完善的企业级 ERP 性质管理系统，主要用于管理企业的订单、库存、财务、发票、车辆、出差等核心业务。系统采用前后端分离架构，前端基于 Vue 2 和 Element UI 构建。

### 主要特性

- **Monorepo 架构**：采用 Yarn Workspaces 统一管理主应用包及共享代码，结构清晰。
- **高精度计算保障**：所有涉及到资金合计、明细运算的核心逻辑均强制通过 `mathjs` 避免精度丢失。
- **高度响应式联动**：系统涉及大量的表单字段和联动计算，所有操作和修改均保证页面的即时联动响应。
- **纯粹 Vue 2 体系**：遵循纯粹的 Vue 2 + Options API + JavaScript 开发体系。

## 🛠️ 技术栈

### 核心框架
- **Vue** 2.6 - 渐进式 JavaScript 框架
- **Vue Router** 3.x - 路由管理器
- **Vuex** 3.x - 状态管理模式
- **Element UI** 2.15 - 页面 UI 组件库

### 依赖与工具库
- **Axios** - HTTP 客户端请求
- **ECharts** - 数据可视化图表
- **Lodash** - JavaScript 实用工具库
- **Mathjs** - 提供精准的数学运算支持
- **Day.js** - 轻量级日期处理库

## 📁 项目结构

项目采用 Yarn Workspace Monorepo 架构：

```text
order-system-ui/
├── packages/
│   ├── order-system/         # 主应用包 (Vue 2 业务代码)
│   │   ├── src/
│   │   │   ├── api/          # API 接口
│   │   │   ├── components/   # 业务组件
│   │   │   ├── views/        # 页面视图 (按业务模块划分)
│   │   │   ├── store/        # Vuex 状态
│   │   │   ├── utils/        # 工具函数
│   │   │   └── ...
│   │   ├── package.json      # 主包配置
│   │   └── vue.config.js     # Vue CLI 配置
│   ├── shared/               # 共享代码包 (通用工具函数、常量、类型等)
│   ├── ui-components/        # 共享 UI 组件库
│   ├── config/               # 共享配置 (ESLint, Babel, Prettier 等)
│   └── request-logger/       # 请求日志工具
├── docker-compose.yml        # Docker 编排配置
├── Dockerfile                # Docker 构建文件
├── nginx.conf                # Nginx 配置
└── package.json              # 根目录配置与工作区脚本
```

## 🚀 快速开始

### 环境要求

- **Node.js** >= 18.20.6
- **Yarn** >= 1.22.0

### 安装依赖

推荐在项目根目录使用 Yarn 进行安装。若遇到包版本兼容性提醒，可使用忽略引擎检查命令：

```bash
# 标准安装
yarn install

# 或忽略引擎版本检查安装
yarn install-order
```

### 开发模式

在根目录运行以下命令直接启动本地开发服务器：

```bash
# 启动 order-system 主应用开发服务器
yarn order
```

### 构建部署

在根目录提供了一系列便捷的构建命令：

```bash
# 构建测试环境 (默认 stage)
yarn build

# 构建生产环境 (prod)
yarn build:prod

# 包含多版本处理逻辑的打包命令
yarn build:ai
yarn build:ai:prod
yarn build:ai:stage
```

## 📦 功能模块

系统涵盖了企业日常运营中诸多核心业务：

- **订单管理**：订单创建、查询、运费佣金及订单调整。
- **库存管理**：主单管理、明细盘点及出库控制。
- **财务管理**：收付款、借贷及回收、账户变动、平账管理、资金变动统计。
- **发票管理**：进项发票、销项发票及其他三方发票。
- **车辆与差旅**：车辆信息、用车申请、出差申请与差旅报销。
- **油卡管理**：油卡档案、充值、消费及资金转移。
- **客户与公司**：供应商及客户档案维护、客户拜访记录。
- **其他模块**：返利、社保、固定资产、报表统计等。

## 📝 开发与代码规范

为了确保系统的稳定和高效，本项目有着极高的代码规范要求，参与开发时需遵循以下原则：

1. **APIfox 驱动**：新增接口或字段必须实时从 APIfox 文档获取，包含字段命名、必填、默认值等规则，杜绝主观臆测。
2. **逻辑高复用**：禁止重复造轮子，在开发前必须检索库内现存逻辑（组件、方法、常量等）并尽量复用。
3. **精度防损**：所有有关金额和计算的逻辑处理，**必须引入并使用 `mathjs` 进行高精度运算与保留**。
4. **状态联动**：保证对页面操作及弹窗修改引发的数据响应式更新。
5. **注释与结构**：添加必要且精简的 `JSDocs` 类型标记与注释。遵循单一职责、开闭等设计模式原则，避免超过 500 行的冗长单文件代码与函数多层嵌套包裹。
6. **语法限制**：全盘采用 Vue 2 Options API 与原生 JavaScript，不使用 TypeScript 及 Vue 3 相关的语法范式。
