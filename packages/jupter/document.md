# 词汇表
库存周转率：评估一段时间内，企业库存物资的周转速度，以及库存资金的占用情况是否合理，简单说，卖得快不快： 库存里的商品是不是能很快地卖出去；货压得多不多： 是不是进了太多的货，或者生产了太多的产品，导致压在仓库里卖不掉
库存周转率 = 销售成本 ÷ 平均库存

库存：仓库积压的货物数量
库存 = 昨日库存 + 今日入库 − 今日出库

当日需求量：客户订单在当天需要发货的数量
当日需求量 = 当日应发货订单数量
数据结构：
| 订单ID | 商品  | 数量  | 发货日期 |
| ---- | --- | --- | ---- |
| O1   | 玻璃A | 100 | 3-12 |
| O2   | 玻璃A | 50  | 3-12 |
| O3   | 玻璃A | 30  | 3-13 |




# 数据源结构说明

## 列结构

| 列名 | 描述 | 示例值 | 类型 |
|------|------|--------|------|
| `Unnamed: 0` | 行索引（读取时生成） | 0, 1, 2 | 通常被删除 |
| `Date` | 日期 | 2023-06-01 | YYYY-MM-DD 格式 |
| `Product_ID` | 产品唯一标识 | P1 | 字符串 |
| `Demand` | 当日需求量 | 51, 141, 172 | 整数 |
| `Inventory` | 当日末库存量 | 5500, 5449, 5308 | 整数 |

---

## 数据示例

```
   Unnamed: 0        Date Product_ID  Demand  Inventory
0           0  2023-06-01         P1      51       5500
1           1  2023-06-02         P1     141       5449
2           2  2023-06-03         P1     172       5308
3           3  2023-06-04         P1      91       5136
4           4  2023-06-05         P1     198       5045
```

---

## 时间范围

示例数据约覆盖 **2023-06-01** 至 **2023-08-01**，按日记录，共约 2 个月。

---

## 处理说明

1. 读取 CSV 后删除 `Unnamed: 0` 列
2. 需求分析使用 `Date` + `Demand`
3. 库存分析使用 `Date` + `Inventory`
