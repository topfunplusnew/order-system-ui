# 常量枚举使用指南

## 概述

本项目在 `src/api/tool/enums.js` 中定义了所有的常量和枚举值，用于统一管理系统中的固定数据和状态值。使用枚举常量可以提高代码的可读性、可维护性，并减少硬编码带来的问题。

## 引入方式

```javascript
// 引入所有枚举
import * as Enums from "@/api/tool/enums";

// 按需引入特定枚举
import {
  TableName,
  moduleNames,
  PaymentState,
  PUBLIC_DICT_TYPE,
} from "@/api/tool/enums";
```

## 使用最佳实践

### 1. 在组件中使用

```javascript
import {
  PaymentState,
  AuditCheckState,
  getTagColor,
  PUBLIC_DICT_TYPE,
} from "@/api/tool/enums";

export default {
  data() {
    return {
      PaymentState, // 直接赋值到 data 中
      statusOptions: PaymentState,
      dictTypeOptions: PUBLIC_DICT_TYPE,
    };
  },
  methods: {
    getStatusColor(status) {
      return getTagColor(status);
    },

    checkPaymentStatus(order) {
      return (
        order.status ===
        this.PaymentState.find((item) => item.value === "已支付")?.value
      );
    },
  },
};
```

### 2. 在模板中使用

```vue
<template>
  <div>
    <!-- 状态选择 -->
    <el-select v-model="form.status">
      <el-option
        v-for="item in PaymentState"
        :key="item.value"
        :label="item.label"
        :value="item.value"
      >
      </el-option>
    </el-select>

    <!-- 状态显示 -->
    <el-tag :type="getStatusColor(item.checkState)">
      {{ item.checkState }}
    </el-tag>

    <!-- 条件渲染 -->
    <el-button
      v-if="item.status === PAYMENT_STATE.UNPAID"
      @click="handlePayment"
    >
      去支付
    </el-button>
  </div>
</template>
```

## 优势

1. **代码可读性**: 使用语义化的常量名称替代魔法数字和字符串
2. **维护性**: 集中管理所有常量，修改时只需改一处
3. **类型安全**: 使用 Object.freeze() 防止意外修改
4. **IDE 支持**: 提供更好的代码补全和错误检查
5. **重构友好**: 重命名或修改值时影响范围明确

## 注意事项

1. **不要修改枚举值**: 所有枚举都使用 Object.freeze() 冻结，避免运行时修改
2. **保持一致性**: 新增枚举时遵循现有命名规范
3. **文档同步**: 修改枚举时同步更新相关文档
4. **向后兼容**: 修改现有枚举值时考虑对历史数据的影响

通过合理使用这些常量和枚举，可以显著提高代码质量，减少 bug，并使代码更容易理解和维护。
