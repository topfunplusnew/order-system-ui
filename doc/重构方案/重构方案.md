所有的目录 都遵守以下结构

company/
    base/
        columns.js  -> 存放表格和表单的列的配置信息
        CompanyForm.vue -> 新增或者修改的表单
    options/
        BankManage.vue
        xxx.vue
    index.vue

column.js中定义了这个页面所需要的业务属性，比如公司名称这个字段，可以配置是否展示在表单，可见性，以及校验规则等，如果不再需要这个字段，直接注释就行

Vue文件上都挂载了一个组件为DialogWrapper 和一个混入 common_dialog  所有任何一个Vue文件，都不需要手动编写弹窗，而是直接通过this.openDialog就可以打开一个弹窗，传入组件后，组件实现handleProcess和handleReject方法就可以实现提交和取消的逻辑

DynamicForm定义了一套通用的表单，可以实现表单项的动态读取、状态清空等逻辑

columnVisibliltyMixin.js中定义了显隐列的逻辑，并且已经注册main.js 每一个组件不需要单独引入，只需要定义好
getStorageKey() {
    return 'company-columns';
},
这是为了区分不同组件的存储状态

并且需要在初始化的时候，执行以下代码：
// 初始化配置管理器
this.configManager = createConfigManager(columnConfig);
this.tableColumns = this.configManager.getTableColumns();
